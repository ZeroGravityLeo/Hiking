# Project Context

This is a Canada-first hiking app and is separate from the Inspection App.

The MVP includes:

- Explore Trails
- Trail Detail
- Missions
- Leaderboard
- Partner Rewards
- Checklists
- Profile
- Admin

Supabase must be separate for this project. Do not connect to the Inspection App Supabase project.

Do not use Inspection database tables or logic, including `inspection_reports`, `repair_tasks`, `contractor_bids`, `inspectors`, `homeowners`, `trade_categories`, or inspection-related workflows.
